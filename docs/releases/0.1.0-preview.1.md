This first NativeCmpKit Maven Central preview publishes all 23 Kira components
independently. Choose the modules your application uses under
`io.github.apdelrahman1911.nativecmpkit`. The file picker and share modules ship
native desktop libraries for Linux x64 and ARM64, macOS Intel and Apple Silicon,
and Windows x64.

- iOS file reads use checked, receiver-owned Foundation copies, handle empty
  files, and report unreadable files as errors.
- Desktop WebView preserves the active JavaFX or application cookie handler.
  Cookie reads leave the active session intact. A handler that cannot clear its
  complete store reports that limitation explicitly.
- The Kira package names replace the prior package identity. Update imports and
  rebuild existing integrations.
- The release uses hosted desktop, browser, emulator, and simulator checks.
  Physical-device coverage will follow separately.

See the [coordinates and setup guide](https://github.com/Apdelrahman1911/NativeCmpKit/blob/main/docs/installation.md).
